# Provenance-Aware-Legal-Zoning-RAG-
Built a production RAG system for NYC zoning Q&amp;A using Groq/Gemini, hybrid BM25 + semantic retrieval (ChromaDB), and citation-grounded responses with source-level traceability and confidence-based abstention. Integrated LangChain agents, FastAPI, SQLite, and deterministic, heuristic, and LLM-judge evaluation.
